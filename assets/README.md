# EvoSphere GUI Assets

Place optional GUI assets in these folders:

- `sprites/` for Evoran and player-token images.
- `guardians/` for Guardian artwork.
- `ui/` for panels, buttons, icons, and board textures.
- `fonts/` for readable game fonts.

The current GUI deliberately uses raylib shapes and text as a safe fallback. A
missing image must never prevent the game from running.
